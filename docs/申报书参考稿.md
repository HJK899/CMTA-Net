## 二、作品摘要（300字内）

老年人跌倒与身体状态异常是老年健康的首要风险源，现有单模态监测（仅穿戴或仅视觉）误报率/漏检率高，且生理（1Hz心率）与行为（30fps姿态）信号异步难融合。本作品提出 CMTA-Net 跨模态时空注意力融合网络：以"异质时间对齐 + 双流编码 + 跨模态互证注意力 + 四态决策"为架构，将生理传感流（脑电/加速度/心率）与视觉行为流（人体姿态骨架）在统一时间轴上互证融合——双向注意力对称KL散度刻画模态印证程度，一致时上调置信、冲突时触发复核，从结构层面抑制误报；并输出可解释的模态一致性分数。在开源数据集上按受试者划分的严格评估中，多部位传感流（脑电+5处穿戴加速度，16通道）取得 F1=0.918±0.004、AUC=0.979±0.001（3 seed），异常召回率0.88~0.97；双模态（UR Fall）3 seed均100%识别；模型仅0.32M参数，适配边缘实时部署。

## 三、作品创新点（评审核心）

1. **跨模态互证注意力（核心创新）**：不同于简单的多模态特征拼接，本作品以"生理↔行为"双向注意力分布的对称KL散度建模模态印证程度，并用一致性分数门控跨模态增强——模态一致时放大互证特征、冲突时抑制并触发复核，从**网络结构层面**抑制误报/漏检，且输出可解释预警信号。
2. **异质时间对齐编码**：将1Hz~30fps跨采样率、天然异步的生理流与行为流统一到同一时间轴，使互证注意力可逐帧对应——解决"异步多模态无法直接融合"的通用瓶颈。
3. **轻量可部署**：全模型0.32M参数、5秒窗口实时推理（CPU毫秒级），适配居家/社区边缘网关；契合4G/NB-IoT低带宽传输链路。
4. **严谨评估协议**：按受试者6:2:2划分杜绝数据泄漏、3随机种子报告均值±标准差、跨库迁移如实报告开放挑战（体现科学严谨性）。

## 四、技术路线（算法模型创新点阐述）

**输入双流**：
- 生理传感流：脑电EEG/三轴加速度/1Hz心率（统一4通道、20Hz重采样）
- 视觉行为流：YOLOv8-Pose提取17关键点骨架（25-30fps）

**四步流程**：
1. 模块① 异质时间对齐编码：低采样率模态插值上采样至统一时间轴（TemporalAlign）；
2. 模块② 双流编码：生理支路轻量1D-CNN+可学习位置编码；行为支路GRU姿态序列编码；
3. 模块③ 跨模态互证注意力融合（核心）：双向注意力A_pb/A_bp → 对称KL一致性 s=1-tanh(KL) → 一致性门控互证增强 z=Proj([H_p+s·A_pb·H_b, H_b+s·A_bp·H_p])；
4. 模块④ 决策头：全局池化+MLP；Focal Loss缓解不平衡；AdamW+warmup+cosine+早停。

**为什么这样设计**：单模态阈值法误报高（弯腰≈跌倒波形）、纯视觉漏检高（遮挡/光照），二者在物理上互补（生理突变×姿态突变）；但在信号异步条件下必须先对齐、再互证，才能让"两路互相印证"这一人类专家判断逻辑在模型中显式成立。

## 五、实验数据与结果

**数据集（全部开源）**：
- UP-Fall：17人、11类活动（5跌倒+6日常）、EEG+5处穿戴IMU+红外 → 传感流主实验
- UR Fall：70段（30跌倒+40日常）视频+配对加速度 → 双模态联合
- 老年腕戴：41名真实老人、984段、三轴加速度+1Hz真实心率 → 真实老人数据与跨域挑战

**评估协议**：按受试者6:2:2划分（测试受试者不参与训练）；5秒窗口；3随机种子。

**主实验结果（UP-Fall，132个未见受试者样本，多部位16通道：脑电+5处加速度）**：
- F1 = 0.9182 ± 0.004；AUC = 0.9793 ± 0.001；异常召回率 0.88~0.97
- 消融：腕戴单点4通道基线 F1=0.8516±0.021 / AUC=0.9282±0.009（多部位融合 +6.7pp F1、+5.1pp AUC，方差更小）

**双模态与消融（UR Fall）**：

| 输入流 | F1 | AUC |
|---|---|---|
| CMTA-Net 双模态 | 1.0000 | 1.0 |
| 单流·传感（消融） | 0.9333 | 0.9796 |
| 单流·行为（消融） | 1.0000 | 1.0 |

**真实老人与跨库（如实定位）**：
- 老年腕戴含真实心率，但模拟跌倒标注噪声大、可分性弱（≈0.55 AUC），作数据获取/处理能力展示；
- 跨库迁移AUC=0.47，如实报告为开放挑战并列入未来工作（域自适应）。

## 六、攻克的实际算法瓶颈（赛道评审要点）

1. **异步异构多模态融合瓶颈**：生理1Hz vs 行为30fps维度不匹配 → 模块①时间对齐解决；
2. **单模态误报/漏检瓶颈**：阈值法误报、纯视觉漏检 → 模块③互证门控从结构抑制；
3. **可解释预警瓶颈**：黑盒分类无法给出"复核依据" → 一致性分数s作为复核信号；
4. **轻量化瓶颈**：双流模型通常数M~数十M参数 → CMTA-Net仅0.32M。

## 七、跨学科融合体现

- 信号处理（生理时序重采样/时间对齐）× 计算机视觉（姿态估计）× 深度学习（注意力/时序建模）× 老年医学/护理场景（健康监测需求）；
- 数据来源横跨穿戴传感（UP-Fall/老年腕戴）与视觉监控（UR Fall）两类采集范式。

## 八、应用前景与价值

- 居家/社区养老双模态联动监测：腕戴（心率+加速度）×摄像头（姿态），跌倒秒级告警、低误报；
- 云-边-端协同：边缘0.32M模型实时推理，异常事件+一致性分数上云复核，适配NB-IoT/4G低带宽；
- 降低护理告警疲劳：一致性分数s作为复核信号，减少无效告警。

## 九、局限与未来工作

1. 双模态配对数据规模有限（UR Fall 70段），需更大规模"生理×视觉"配对数据；
2. 跨域迁移失败（AUC 0.47），未来引入域自适应/跨域校准；
3. 一致性分数在小数据下区分度有限，未来以辅助一致性损失引导；
4. 个性化基线先验（模块④扩展）与新用户冷启动——复赛工作项；
5. 四态联合诊断（正常/生理异常/行为异常/联合异常）——复赛扩展。
