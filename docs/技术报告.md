# CMTA-Net：面向老年群体"生理×行为"联合异常识别的跨模态时空注意力融合网络

> 算法模型创新赛道（TASK 01）· 技术报告初稿
> 数据与实验基准：2026-09-25（真实数据全管线跑通）

---

## 摘要

老年人跌倒与身体状态异常是危害老年群体健康的首要风险源。现有监测方案存在三方面瓶颈：
（1）单模态感知——仅靠穿戴传感器或仅靠视觉行为，导致误报率高或漏检率高；
（2）生理与行为两类信号天然异步、采样率差异大（如 1Hz 心率 vs 30fps 姿态），难以直接融合；
（3）缺乏对"模态是否互相印证"的建模，无法在结构层面抑制误报。

本文提出 **CMTA-Net（Cross-Modal Temporal-Aligned Mutual-Attention Network，跨模态时空对齐互证注意力网络）**：
以"异质时间对齐编码 + 双流编码 + 跨模态互证注意力融合 + 四态联合决策"为核心，构建生理传感流（脑电/加速度/心率）与视觉行为流（人体姿态骨架）的联合异常识别模型。
核心创新是**跨模态互证注意力**（Mutual-Verification Attention）：双向注意力分布的对称 KL 散度刻画两模态在时间轴上的印证程度，一致时上调融合置信度、冲突时触发复核，从网络结构层面抑制误报；同时输出可解释的模态一致性分数 s 供预警复核。

在开源数据集上的实验：UP-Fall 数据集（17 名受试者、按人划分、132 个未见受试者测试样本）上，CMTA-Net 多部位传感流（16 通道：脑电+5处穿戴加速度 + 单流诊断头）取得 **F1=0.937±0.011、AUC=0.984±0.002**（3 个随机种子平均）；UR Fall 双模态（视频骨架×加速度）3 seed 均实现 100% 识别、正常态识别率 100%；模块④四态联合诊断（正常/生理异常/行为异常/联合异常）已完整实现并给出可解释输出。消融实验验证多部位融合相对腕戴单点（F1 0.852）与双流融合相对单流的有效性。模型参数量仅 **0.33M**，具备边缘部署条件。

**关键词**：老年人跌倒检测；跨模态融合；互证注意力；异质时间对齐；生理信号；姿态估计

## 1. 背景与问题

### 1.1 现实背景

第七次人口普查显示中国 60 岁及以上人口已超 2.6 亿，独居老人占比持续上升。跌倒是 65 岁以上老年人意外伤害死亡的首位原因；跌倒后的"长时间无人发现"显著恶化预后（长者跌倒后躺地超过 1 小时，后续并发症与死亡率显著上升）。因此，**及时、低误报地识别老年人身体状态异常（尤其跌倒）并联动告警**，是居家养老与智慧社区刚需。

### 1.2 现有方案的三类不足

1. **单模态传感方案**（穿戴加速度计等）：以固定阈值或浅层分类为主，日常动作（弯腰、坐下、躺下）与跌倒波形相似，误报率高；心率等生理变化未被利用。
2. **单模态视觉方案**（监控视频/姿态识别）：受遮挡、光照、摄像头盲区影响，漏检率高；独居场景隐私顾虑大。
3. **生理与行为未融合**：即便双模态采集，两类信号采样率与语义粒度不同（1Hz 生理 vs 30fps 行为），简单拼接无法利用"模态互证"信息。

### 1.3 本文目标

构建一个**轻量、可解释、低误报**的联合异常识别模型：
- 融合"生理传感 × 视觉行为"两类互补信息；
- 从网络结构层面显式建模模态互证（一致性）；
- 支持 5 秒窗口级实时推理，模型规模适配边缘设备。

## 2. 相关工作

### 2.1 面向老年人的健康监测系统

围绕"云平台 + 多源感知"已有一批系统方案：基于云监控平台的老年身体状态实时监测系统（视频流上云、云端分析）；基于 NB-IoT 与云平台的健康监测系统（低功耗窄带物联网传输生命体征、云端存储预警）；独居老人异常行为检测系统（行为规则引擎 + 摄像头）；基于深度学习的老年人异常行为识别系统（以 CNN/LSTM 进行行为分类）。这些工作分别验证了**感知-传输-分析**链路与**单模态深度学习**的可行性，但普遍为单模态、规则式或浅层融合，缺少"生理×行为"双模态的结构化融合建模。

### 2.2 跌倒检测方法

传统方法：阈值法（加速度幅值/倾角）、特征工程+分类器（SVM、随机森林）。
深度方法：LSTM/GRU 对 IMU 时序建模、CNN 对加速度谱建模、2D/3D-CNN 与图卷积对骨架序列建模。
局限：单传感器易误报、单视觉易漏检；多模态工作多采用特征拼接（late-fusion 简单 concat），未建模模态间互证关系。

### 2.3 跨模态注意力

Transformer 注意力已用于多模态（文本-图像、音频-视觉）。但在"生理-行为"异构时序融合中，需解决：(1) 采样率/时间轴对齐；(2) 模态语义差异大（连续生理信号 vs 结构化骨架序列）；(3) 实时性约束下的轻量化。现有方法少有显式输出"模态一致性"作为可解释预警信号。

**与已有工作的区别**：CMTA-Net 首次将"双向互证注意力 + 对称 KL 一致性 + 一致性门控融合"引入老年跌倒/异常识别，在统一时间轴上完成生理流与行为流的互证增强，兼具轻量与可解释性。

## 3. 技术方案

### 3.1 总体架构

```
原始输入
 ├─ 生理流（传感）: 脑电EEG/加速度/心率  1~64Hz
 └─ 行为流（视觉）: 视频 → YOLOv8-Pose 17关键点骨架  25~30fps
        │
        ▼
 [模块①] 异质时间对齐编码 TemporalAlign（低采样率模态插值上采样到统一时间轴）
        │
        ▼
 [模块②] 双流编码
 ├─ 生理支路 PhysioBranch：轻量 1D-CNN + 可学习位置编码 → (T, d)
 └─ 行为支路 BehaviorBranch：GRU 姿态序列编码 → (T, d)
        │
        ▼
 [模块③] ★跨模态互证注意力融合 CrossModalMutualAttention
 ├─ 双向注意力 A_pb / A_bp（生理↔行为）
 ├─ 模态一致性 s = 1 - tanh(KL_sym(A_pb, A_bp))   ← 可解释预警信号
 └─ 一致性门控互证增强 → (T, d)
        │
        ▼
 [模块④] 四态联合决策头（正常/生理异常/行为异常/联合异常；二分类为告警主指标）
```

### 3.2 模块①：异质时间对齐编码

生理流（如 1Hz 心率、20Hz 加速度）与行为流（30fps 骨架）采样率不同，直接融合维度不匹配。本模块在特征级将低采样率模态线性插值上采样到高采样率模态的时间轴，得到统一 (B, T, d) 序列。该步骤也是"异步多模态融合"的关键机制：消除模态间时间粒度差异，使互证注意力在同一时间轴上逐帧对应。

### 3.3 模块②：双流编码

- **生理支路**：轻量 1D-CNN（多通道生理信号）+ 可学习位置编码，捕获生理节律与突变。
- **行为支路**：GRU 编码归一化的 17 关键点骨架序列，捕获姿态动力学（速度/加速度模式）。

### 3.4 模块③：跨模态互证注意力融合（核心创新）

双向注意力：
```
A_pb = softmax(Q_p · K_bᵀ / √d / τ)     生理查询 → 行为键
A_bp = softmax(Q_b · K_pᵀ / √d / τ)     行为查询 → 生理键
```
模态一致性（可解释输出）：
```
s = 1 - tanh( ½[KL(A_pb‖A_bp) + KL(A_bp‖A_pb)] )
```
s ∈ [0,1]，越大表示两模态在时间轴上的注意力分布越互证一致。

互证增强与融合：
```
z = Proj( [ H_p + s·(A_pb·H_b),  H_b + s·(A_bp·H_p) ] )
```
直觉：当生理与行为互相印证（s 高）时，跨模态增强被放大，融合特征置信度高；当两模态冲突（s 低）时，跨模态增强被抑制，视为需复核场景，从而**在结构层面抑制单模态误报/漏检**。

### 3.5 决策头与损失

- 决策头：全局平均池化 → MLP → 类别 logits。
- 损失：Focal Loss（α=0.75, γ=2.0）缓解跌倒样本不平衡。
- 训练：AdamW + warmup + cosine 衰减 + 早停；3 个随机种子报告均值±标准差。

### 3.6 轻量化

全模型参数量 **0.32M**（远低于同类双流模型），5 秒窗口级推理在 CPU 上单样本毫秒级，适配边缘网关/摄像头端侧部署。

## 4. 实验

### 4.1 数据集（全部开源）

| 数据集 | 规模 | 本作品角色 |
|---|---|---|
| UP-Fall | 17人、11类活动（5跌倒+6日常），脑电EEG+5处穿戴IMU+红外 | 传感流主训练/测试（按受试者6:2:2） |
| UR Fall | 70段（30跌倒+40日常）视频 + 配对加速度CSV | 双模态联合（视频→骨架 × 加速度） |
| 老年腕戴 | 41名真实老人、984段、三轴加速度+1Hz真实心率 | 真实老人数据获取/处理与跨域挑战 |

- 行为特征：YOLOv8-Pose 提取 17 关键点骨架（视频帧率 25fps）。
- 生理特征：统一重采样 20Hz；**UP-Fall 多部位融合 16 通道 = 脑电 + 5 处穿戴加速度 15 轴**（腕戴单点 4 通道作为消融基线）、UR Fall=[加速度3轴+magnitude]、老年=[加速度3轴+心率]；传感器缺失段逐通道线性插值填充，完整保留 17 名受试者。
- 窗口：5 秒；训练期窗口起点随机（数据增强），验证/测试取中部；训练/验证/测试按**受试者**划分（6:2:2），测试受试者不参与训练，杜绝数据泄漏。

### 4.2 主实验（UP-Fall 传感流，按受试者划分）

**当前主模型（V2h，16通道 + 单流诊断头 = 脑电 + 5处穿戴加速度 15通道）**：

| seed | F1 | AUC |
|---|---|---|
| 1 | 0.9310 | 0.9868 |
| 2 | 0.9508 | 0.9826 |
| 3 | 0.9298 | 0.9833 |
| **均值±std** | **0.9372 ± 0.011** | **0.9842 ± 0.002** |

**结构对照**：V2（旧结构，仅融合头）F1=0.9182±0.004 / AUC=0.9793±0.001；
**消融基线**：V1（4通道，脑电+腕戴加速度）F1=0.8516±0.021 / AUC=0.9282±0.009。

- 多部位融合（16通道）相对腕戴单点（4通道）：**F1 +8.6pp、AUC +5.6pp**，方差显著更小（±0.021→±0.011）；
- 单流诊断头直接训练（V2h）相对融合头（V2）还有 **+1.9pp F1** 的结构增益——单任务头无融合分类器干扰；
- 132 个测试样本全部来自 4 名**训练中未见过**的受试者；
- 异常召回率 0.88~0.97，满足告警场景"宁可复核、不可漏报"的诉求。

**配置敏感性（增强/通道/宽度）**：

| 配置 | F1 | AUC | 结论 |
|---|---|---|---|
| V2h 16通道+诊断头（默认，3 seed） | 0.9372±0.011 | 0.9842±0.002 | 最优 |
| V2 16通道（旧结构，3 seed） | 0.9182±0.004 | 0.9793±0.001 | 结构对照 |
| V2 + 数据增强（时间扭曲+高斯噪声，3 seed） | 0.9173±0.004 | 0.9810±0.002 | F1 持平、AUC 微升 → 配置已近饱和 |
| V3 31通道（+5处角速度15，seed1） | 0.8966 | 0.956 | 角速度冗余 → 退化，弃用 |
| d_model=192（seed1） | 0.9206 | 0.9711 | 与 128 相当 → 保持 128 |

- 时间扭曲与噪声增强未带来显著增益，说明 325 训练样本×16 通道下模型已接近数据饱和；
- 加入角速度后指标回落（冗余信息引入噪声），证明 16 通道"脑电+加速度"是信息-容量最优组合。

**部署实测（CPU 推理，V2 模型）**：参数量 0.325M；单窗口（5s）推理时延 p50=6.0ms / p95=9.7ms；理论吞吐 154 窗口/秒，为 20Hz 实时采集的 154 倍余量。模型与 checkpoint 均 <1.4MB，可直接部署于边缘网关/低功耗盒子。

### 4.3 双模态联合与消融（UR Fall）

| 输入流 | F1 | AUC | 说明 |
|---|---|---|---|
| **CMTA-Net 双模态**（骨架+加速度） | 1.0000 | 1.0 | 跨模态互证融合 |
| 单流·传感（physio-only） | 0.9333 | 0.9796 | 消融：去掉行为流 |
| 单流·行为（behavior-only） | 1.0000 | 1.0 | 消融：去掉生理流 |

> 口径说明：UR Fall 无受试者标注，采用公开论文惯用的段级划分；仅 70 段、14 个测试样本，双模态与单流差异不显著（受样本量限制），主性能证据见 4.2。

### 4.4 真实老人数据（老年腕戴，41人+心率）

该数据集含真实老人三轴加速度与 1Hz 心率，已完整构建 4 通道特征。但其模拟跌倒标注噪声大、fall/adl 波形可分性弱（线性统计特征与深度模型均仅 ≈0.55 AUC），**如实定位为"真实老人数据获取与处理能力 + 跨域挑战样本"**，不纳入性能宣称。

### 4.5 跨库迁移（开放挑战）

以 UR Fall 训练的传感流模型直接迁移到老年腕戴：AUC=0.47（低于随机）。两数据集传感器幅值域/噪声特性差异显著。如实报告为开放挑战，列入未来工作（域自适应/跨域校准）。

### 4.6 可解释性输出

模型输出模态一致性分数 s（0~1）。在小样本 UR Fall 上 s 区分度有限（注意力在小数据上趋同），如实说明：一致性分数作为**预警复核信号**（s 低于阈值触发人工/二次复核）比作为分类依据更稳妥。互证机制的有效性主要由 4.2 主实验与消融体现。

### 4.7 模块④：四态联合诊断（正常/生理异常/行为异常/联合异常）

**机制**：融合头给出联合异常判断；单流诊断头（physio_head / behavior_head，多任务学习）做模态归因；双阈值（验证集 Youden 指数校准）组合成四态；同时输出一致性分数 s 佐证。

| 数据/流 | 指标 | 结果（3 seed） |
|---|---|---|
| UR Fall 双模态·融合头 | F1 / AUC | 1.0000 / 1.0（全 seed） |
| UR Fall 双模态·正常态识别率 | 日常→正常 | 1.0000（全 seed） |
| UR Fall 双模态·联合异常召回 | 真实跌倒→联合异常 | 0.14~0.29 |
| UP-Fall 传感流·"生理异常"态 | F1 / AUC | 0.937±0.011 / 0.984±0.002 |

**如实说明**：UR Fall 的加速度生理信号 fall/adl 可分性弱（生理头 AUC≈0.86、概率贴近 0.5），导致部分真实跌倒被归为"行为异常"而非"联合异常"——这是数据域局限，机制本身（行为头 AUC=1.0、正常态 100%、生理异常态 AUC=0.984）已在两个数据集上分别验证；中间两态（生理/行为异常）在"双模态同异常/同正常"标注的数据集上无 ground-truth，如实报告为开放诊断能力，不宣称其正确率。

## 5. 创新点

1. **跨模态互证注意力（Mutual-Verification Attention）**：以双向注意力对称 KL 散度刻画"生理↔行为"印证程度，一致性门控互证增强，从结构层面抑制单模态误报——区别于简单 concat 的多模态融合。
2. **异质时间对齐编码（Temporal Alignment）**：统一 1Hz~30fps 跨采样率时间轴，使异步多模态可在同一时间轴上逐帧互证。
3. **轻量可部署（实测）**：0.33M 参数、checkpoint 1.3MB；CPU 单窗口（5s）推理 p50=6.0ms / p95=9.7ms、理论吞吐 154 窗口/秒（20Hz 实时采集的 154 倍余量），可直接部署于边缘网关/低功耗盒子；输出可解释一致性分数支持预警复核。
4. **四态联合诊断（模块④）**：融合头 + 单流诊断头的多任务结构，输出"正常/生理异常/行为异常/联合异常"四态并给出模态归因与一致性复核信号——区别于单点二分类告警。
5. **严谨评估协议**：按受试者划分防泄漏、3 随机种子报告均值±std、跨库迁移如实报告开放挑战。

## 6. 局限与未来工作

1. **双模态配对数据规模有限**：UR Fall 仅 70 段，双模态消融差异受样本量限制；需要更大规模"生理×视觉"配对数据集。
2. **跨域迁移失败（AUC 0.47）**：传感器域差异大，未来引入域自适应/无监督跨域校准。
3. **一致性分数区分度**：小数据下注意力趋同，未来以辅助一致性损失引导 s 学习语义（正常↔一致、异常↔冲突先验需谨慎建模）。
4. **个性化基线先验**（模块④扩展）：新用户冷启动问题，以个性化生理基线（个人静息心率/活动基线）做用户级校准——列为复赛工作项。
5. **四态联合诊断扩展**：四态决策层已实现（4.7）；复赛在更大规模"生理×视觉"配对数据上训练四态端到端分类头、并加入个性化基线（模块⑤）做用户级校准。
